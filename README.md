# Ёлочка Плюс — экранный переводчик с историей, словарём и экспортом в Quizlet

Расширенный аналог «Ёлочки»: выдели область экрана горячим клавишей `~` —
текст распознается (OCR), очистится от мусора и переведётся (Google Translate)
менее чем за 2 секунды. Перевод всплывает у курсора, история и словарь хранятся
в SQLite, из словаря можно выгрузить пары для Quizlet.

## Структура проекта

```
yolochka/
├── main.py            # точка входа: трей, глобальный хоткей (Win32 RegisterHotKey), сборка модулей
├── gui.py             # QMainWindow с вкладками История/Словарь/Настройки, темы, I18n-менеджер
├── capture.py         # оверлей затемнения + выделение области, попап перевода у курсора
├── translator.py      # предобработка (Оцу), OCR (EasyOCR/Tesseract), regex-очистка, QThread-перевод
├── database.py        # SQLite: history / dictionary / settings (потокобезопасно, WAL)
├── locales/
│   ├── en.json        # локализация UI (английский)
│   └── ru.json        # локализация UI (русский)
├── requirements.txt
├── yolochka.spec      # конфиг PyInstaller для portable EXE
├── app.log            # создаётся автоматически (логирование всех этапов)
└── yolochka.db        # создаётся автоматически рядом с exe
```

## Установка и запуск (dev)

```bash
pip install -r requirements.txt
python main.py
```

Сборка автономного EXE (одним файлом, без консоли):

```bash
pyinstaller yolochka.spec
# результат: dist/YolochkaPlus.exe + папка locales рядом (добавляется spec'ом)
```

## Как добавить новый язык

1. **Язык перевода** — просто допишите ISO-код в список
   `SUPPORTED_TRANSLATE_LANGS` в `translator.py`. Логика не меняется:
   код уходит прямо в `GoogleTranslator(target=...)`.
2. **Язык экрана (OCR)** — добавьте маппинг в `EASYOCR_LANG_MAP` /
   `TESSERACT_LANG_MAP` (одна строка вида `"sv": "swedish"`).
3. **Язык интерфейса** — положите файл `locales/<код>.json` (копия en.json
   с переведёнными значениями). `I18n` подхватит его автоматически, он появится
   в настройках «Язык интерфейса приложения» и переключит UI на лету.

## Горячие клавиши и настройки

Хоткей (`grave` = тильда `~`), языки `source_lang`/`target_lang`, тема
(Luxury Dark / Clean Light), движок OCR и задержка попапа хранятся в таблице
`settings` БД и меняются через вкладку «Настройки» без перезапуска.

## Экспорт для Quizlet

Вкладка «Словарь» → «Экспорт для Quizlet (.txt)»: файл вида

```
hello	привет
world	мир
```

(термин и определение разделены табуляцией — формат импорта Quizlet).
«Экспорт в CSV» даёт полный набор колонок с парами языков и датой.

## Отладка

Все этапы пишутся в `app.log`: время OCR и перевода по фазам, пороги Оцу,
переключения языков, ошибки API, экспорт. Уровень DEBUG включён всегда;
в dev-режиме дублируется в консоль.
